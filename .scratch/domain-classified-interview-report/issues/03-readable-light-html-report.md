# 03: 生成舒适可导航的浅色 HTML 报告

**What to build:** 使用与 Markdown 相同的分类数据生成固定浅色、响应式且适合长时间阅读的 HTML。用户可以通过领域导航快速定位题目，通过面经原文标题跳转上下文，并在末尾按需展开完整原文。

**Blocked by:** 01: 生成首个 DeepSeek 领域化 Markdown 报告

**Status:** ready-for-agent

- [ ] HTML 与 Markdown 使用相同的领域顺序、题目集合、来源关系和统计口径。
- [ ] 页面使用固定浅色主题，正文、卡片、边框、强调色和背景具有舒适且清晰的对比度。
- [ ] 页面采用适合长文阅读的内容宽度、行高、段间距和卡片留白。
- [ ] 桌面端提供清晰的领域导航，窄屏下不会出现导航遮挡、横向溢出或不可读文本。
- [ ] 顶部展示各领域题目数和来源文章数，并由真实分类结果计算。
- [ ] 题目只在主领域章节出现一次，题目卡片只显示面经原文标题标签。
- [ ] 点击面经原文标题标签可以跳转到报告末尾对应的唯一原文。
- [ ] 所有参与分类的面经原文都完整进入 HTML 附录并默认折叠。
- [ ] 原文区域保留来源平台和外部原始链接。
- [ ] “其他”领域固定排在最后，没有题目时不制造误导性的静态内容。
- [ ] 抓取内容和模型输出中的 HTML、脚本片段及特殊字符不会执行脚本、破坏 DOM 或污染导航。
- [ ] 现有静态高频考点不再出现在 HTML 中。
- [ ] 自动化测试验证领域导航、统计、来源锚点、完整折叠原文和危险内容转义。
- [ ] 使用桌面和窄屏尺寸完成一次真实浏览器视觉烟测。
