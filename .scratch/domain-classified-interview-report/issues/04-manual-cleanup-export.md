# 04: 支持人工清理并导出清理版报告

**What to build:** 在 HTML 报告中提供不破坏源数据的人工清理流程。用户可以软删除不需要的题目、撤销误删、看到同步更新的统计，并导出固化当前结果且仍可继续编辑的清理版报告。

**Blocked by:** 03: 生成舒适可导航的浅色 HTML 报告

**Status:** ready-for-agent

- [ ] 每道题提供清晰但不过度干扰阅读的软删除入口。
- [ ] 软删除只影响当前页面，不修改抓取 JSON、原始 HTML 或 Markdown。
- [ ] 删除题目后，对应领域的可见题目数量和来源文章数量立即更新。
- [ ] 某领域没有任何可见题目后，其正文章节和导航入口自动隐藏。
- [ ] 删除与撤销不会改写题目的外部来源 URL 或抓取数据。
- [ ] 页面提供短时撤销入口，能够恢复最近删除的题目、统计和领域显示。
- [ ] 页面提供导出清理版 HTML 的操作，整个过程在浏览器本地完成，不上传报告内容。
- [ ] 导出的清理版不包含已经删除的题目，并固化导出时的统计与可见领域。
- [ ] 导出的清理版仍保留软删除、撤销和再次导出能力。
- [ ] 刷新原始生成报告会恢复尚未导出的软删除，不建立跨报告持久化删除记录。
- [ ] 导出操作不会覆盖原始生成报告，而是产生独立文件。
- [ ] 真实浏览器烟测验证删除、统计更新、空领域隐藏、撤销、来源直链、导出和再次编辑。
