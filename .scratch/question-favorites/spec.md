# 面试题收藏夹

在 HTML 报告的导航中增加常驻的“收藏夹”，每道面试题后提供可点击、可键盘操作的 ☆/★，收藏夹展示问题与原文链接并支持取消收藏。

## 实现边界

- 复用静态 HTML 架构，通过 localStorage 保存当前浏览器中的收藏。
- 按原文身份与题目文本关联收藏，题目重排不影响身份；不同来源的同名题目独立收藏，同一来源的相同题目在收藏夹去重。
- 收藏夹副本不参与题目、来源及领域统计。
- 删除原题后隐藏对应收藏，撤销后恢复；删除不取消星标。
- 导出的清理版只保留未删除原题，携带星标快照，打开后重建收藏夹，仍可编辑与再次导出。
- 存储不可用或数据损坏时保持页面功能可用，不修改抓取数据、Markdown 或分类逻辑。
- 使用现有分类结果升级当前主要 HTML 报告，不重新调用分类模型。

## 验收

验证新增、取消、刷新恢复、原文链接、去重与统计、删除与撤销、导出再打开和继续编辑，以及存储故障与窄屏布局。
