# Triage 标签

Engineering skills 使用五种规范 triage 角色。下表定义这些角色在本仓库 issue tracker 中使用的实际标签字符串。

| mattpocock/skills 中的标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个角色，例如“应用 AFK-ready triage 标签”时，使用本表对应的标签字符串。

如需适配现有词汇，可修改中间一列。
